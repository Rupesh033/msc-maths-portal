Q1. Define Wronskian of \(n\) functions. [2 Marks]

Let \(f_1,f_2,\ldots,f_n\) be \((n-1)\)-times differentiable functions on an interval \(I\). The Wronskian of these functions is defined as the determinant

\[ W(f_1,f_2,\ldots,f_n)(x)= \begin{vmatrix} f_1(x)&f_2(x)&\cdots&f_n(x)\\ f_1'(x)&f_2'(x)&\cdots&f_n'(x)\\ \vdots&\vdots&\ddots&\vdots\\ f_1^{(n-1)}(x)&f_2^{(n-1)}(x)&\cdots&f_n^{(n-1)}(x) \end{vmatrix}. \]

Equivalently, \(W(x)=\det\left(f_j^{(i-1)}(x)\right)_{1\le i,j\le n}\).

If \(f_1,\ldots,f_n\) are linearly dependent on \(I\), then \(W(x)\equiv 0\) on \(I\).

The converse is not true for arbitrary differentiable functions; however, for solutions of a linear homogeneous ODE, \(W\equiv 0\) iff the solutions are linearly dependent.

Q2. State Lipschitz condition. [2 Marks]

Let \(f(x,y)\) be defined on a domain \(D\subseteq \mathbb{R}^2\). The function \(f\) is said to satisfy the Lipschitz condition in \(y\) on \(D\) if there exists a constant \(L>0\) such that

\[ |f(x,y_1)-f(x,y_2)|\le L|y_1-y_2| \]

for all \((x,y_1),(x,y_2)\in D\).

The constant \(L\) is called the Lipschitz constant and is independent of \(y_1,y_2\) on the specified domain.

If \(f\) and \(\partial f/\partial y\) are continuous on a rectangle, then \(f\) satisfies a Lipschitz condition in \(y\) there.

This condition is a sufficient condition for uniqueness of solutions of the initial value problem.

Q3. Define linearly independent functions. [2 Marks]

A set of functions \(\{f_1,f_2,\ldots,f_n\}\) defined on an interval \(I\) is said to be linearly independent on \(I\) if the identity

\[ c_1f_1(x)+c_2f_2(x)+\cdots+c_nf_n(x)=0,\quad \forall x\in I, \]

implies that

\[ c_1=c_2=\cdots=c_n=0. \]

Here \(c_1,c_2,\ldots,c_n\) are constants.

If there exists a nontrivial choice of constants, not all zero, satisfying the above identity, then the functions are linearly dependent.

Linear independence is a property of the set of functions on the whole interval \(I\), not merely at a single point.

Q4. Define Sturm–Liouville problem. [2 Marks]

A Sturm–Liouville problem consists of a second-order linear differential equation of the form

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+\bigl(q(x)+\lambda r(x)\bigr)y=0,\quad a\le x\le b, \]

together with homogeneous boundary conditions

\[ \alpha_1 y(a)+\beta_1 p(a)y'(a)=0,\qquad \alpha_2 y(b)+\beta_2 p(b)y'(b)=0, \]

where not both coefficients in each condition are zero.

Here \(\lambda\) is the eigenvalue parameter, \(p(x)>0\), \(r(x)>0\), and \(p,p',q,r\) are continuous on \([a,b]\).

The values of \(\lambda\) for which nontrivial solutions exist are called eigenvalues, and the corresponding solutions are eigenfunctions.

Q5. Define Green's function. [2 Marks]

Let \(L\) be a linear differential operator and consider the boundary value problem

\[ L[y]=f(x),\qquad B[y]=0, \]

where \(B[y]=0\) denotes homogeneous boundary conditions.

A Green's function for this problem is a function \(G(x,\xi)\) such that

\[ L_xG(x,\xi)=\delta(x-\xi), \]

and \(G(x,\xi)\), as a function of \(x\), satisfies the homogeneous boundary conditions.

The solution is then represented as

\[ y(x)=\int_a^b G(x,\xi)f(\xi)\,d\xi. \]

For a second-order self-adjoint operator \(L[y]=(p y')'+q y\), \(G\) is continuous at \(x=\xi\), and its derivative has the jump

\[ \left.\frac{\partial G}{\partial x}\right|_{x=\xi+} -\left.\frac{\partial G}{\partial x}\right|_{x=\xi-} =\frac{1}{p(\xi)}. \]

Q6. Write Picard's iteration formula. [2 Marks]

Consider the initial value problem

\[ \frac{dy}{dx}=f(x,y),\qquad y(x_0)=y_0. \]

This is equivalent to the integral equation

\[ y(x)=y_0+\int_{x_0}^{x}f(t,y(t))\,dt. \]

Picard's iteration formula is

\[ y_{n+1}(x)=y_0+\int_{x_0}^{x}f(t,y_n(t))\,dt,\qquad n=0,1,2,\ldots \]

The initial approximation is chosen as

\[ y_0(x)=y_0. \]

Under continuity and Lipschitz conditions on \(f\), the sequence \(\{y_n(x)\}\) converges uniformly to the unique solution of the initial value problem.

Q7. Define boundary value problem. [2 Marks]

A boundary value problem consists of an ordinary differential equation together with conditions imposed at more than one point of the interval of definition.

For a second-order linear differential equation

\[ y''+P(x)y'+Q(x)y=R(x),\qquad a\le x\le b, \]

typical boundary conditions are

\[ \alpha_1y(a)+\beta_1y'(a)=\gamma_1,\qquad \alpha_2y(b)+\beta_2y'(b)=\gamma_2. \]

Here the conditions are prescribed at the endpoints \(x=a\) and \(x=b\).

Unlike an initial value problem, a boundary value problem may have no solution, a unique solution, or infinitely many solutions.

Existence and uniqueness depend on the differential equation, the boundary conditions, and the interval.

Q8. Define Wronskian and state its property regarding linear independence. [2 Marks]

For \((n-1)\)-times differentiable functions \(f_1,\ldots,f_n\) on an interval \(I\), the Wronskian is

\[ W(f_1,\ldots,f_n)(x)= \begin{vmatrix} f_1(x)&f_2(x)&\cdots&f_n(x)\\ f_1'(x)&f_2'(x)&\cdots&f_n'(x)\\ \vdots&\vdots&\ddots&\vdots\\ f_1^{(n-1)}(x)&f_2^{(n-1)}(x)&\cdots&f_n^{(n-1)}(x) \end{vmatrix}. \]

If \(f_1,\ldots,f_n\) are linearly dependent on \(I\), then \(W(x)\equiv 0\) on \(I\).

However, for arbitrary differentiable functions, \(W\equiv 0\) does not necessarily imply linear dependence.

If \(f_1,\ldots,f_n\) are solutions of an \(n\)-th order linear homogeneous ODE with continuous coefficients on \(I\), then either \(W(x)\neq 0\) for all \(x\in I\) or \(W(x)\equiv 0\) on \(I\).

In that case, \(W\equiv 0\) iff the solutions are linearly dependent.

Q9. Define linearly dependent functions. [2 Marks]

A set of functions \(\{f_1,f_2,\ldots,f_n\}\) defined on an interval \(I\) is said to be linearly dependent on \(I\) if there exist constants \(c_1,c_2,\ldots,c_n\), not all zero, such that

\[ c_1f_1(x)+c_2f_2(x)+\cdots+c_nf_n(x)=0 \]

for every \(x\in I\).

Equivalently, at least one of the functions can be expressed as a linear combination of the remaining functions on \(I\).

If no such nontrivial set of constants exists, then the functions are linearly independent.

Linear dependence is defined over the whole interval \(I\), not merely at isolated points.

Q10. Define self-adjoint boundary value problem. [2 Marks]

A second-order linear differential equation is said to be in self-adjoint form if it can be written as

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+q(x)y=0, \]

where \(p(x)\) and \(q(x)\) are real-valued continuous functions on \([a,b]\), and \(p(x)>0\) on \([a,b]\).

A self-adjoint boundary value problem consists of such a self-adjoint differential equation together with boundary conditions of the form

\[ \alpha_1 y(a)+\beta_1 y'(a)=0,\qquad \alpha_2 y(b)+\beta_2 y'(b)=0, \]

where the coefficients are real and not both zero in each condition.

The operator \(L[y]=\frac{d}{dx}\left(p\frac{dy}{dx}\right)+qy\) is called a self-adjoint operator, and it satisfies Lagrange's identity:

\[ \int_a^b \left(u\,L[v]-v\,L[u]\right)dx=0 \]

for functions \(u,v\) satisfying the boundary conditions.

Q11. State jump discontinuity property of Green's function derivative. [2 Marks]

Let \(G(x,\xi)\) be the Green's function for the self-adjoint boundary value problem

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+q(x)y=f(x),\qquad a\le x\le b, \]

with homogeneous boundary conditions. Then \(G(x,\xi)\) satisfies the following properties:

1. \(G(x,\xi)\) is continuous at \(x=\xi\).

2. \(G(x,\xi)\) satisfies the homogeneous differential equation for \(x\neq \xi\).

3. \(G(x,\xi)\) satisfies the given homogeneous boundary conditions as a function of \(x\).

The jump discontinuity property states that the derivative of \(G(x,\xi)\) with respect to \(x\) has a jump discontinuity at \(x=\xi\), given by

\[ \left.\frac{\partial G}{\partial x}\right|_{x=\xi^+} -\left.\frac{\partial G}{\partial x}\right|_{x=\xi^-} =\frac{1}{p(\xi)}. \]

This jump condition is essential for constructing the Green's function and for solving boundary value problems.

Q12. Define eigenvalue and eigenfunction. [2 Marks]

Consider the Sturm–Liouville boundary value problem

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+\bigl(q(x)+\lambda r(x)\bigr)y=0,\qquad a\le x\le b, \]

with homogeneous boundary conditions.

The values of the parameter \(\lambda\) for which the boundary value problem has a nontrivial solution (i.e., \(y\not\equiv 0\)) are called eigenvalues (or characteristic values or characteristic numbers).

The corresponding nontrivial solutions \(y(x)\) are called eigenfunctions (or characteristic functions).

For a regular Sturm–Liouville problem, the eigenvalues form a real, infinite, discrete sequence

\[ \lambda_1<\lambda_2<\lambda_3<\cdots,\qquad \lambda_n\to\infty, \]

and the corresponding eigenfunctions \(y_n(x)\) are orthogonal with respect to the weight function \(r(x)\):

\[ \int_a^b y_m(x)y_n(x)r(x)\,dx=0,\qquad m\neq n. \]

Q13. Write formula for reduction of order. [2 Marks]

Consider the second-order linear homogeneous differential equation

\[ y''+P(x)y'+Q(x)y=0. \]

Suppose \(y_1(x)\) is a known non-zero solution of this equation. Then a second linearly independent solution \(y_2(x)\) is given by the reduction of order formula:

\[ y_2(x)=y_1(x)\int\frac{e^{-\int P(x)\,dx}}{[y_1(x)]^2}\,dx. \]

Equivalently, if the differential equation is in the self-adjoint form

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+q(x)y=0, \]

then the second solution is

\[ y_2(x)=y_1(x)\int\frac{1}{p(x)[y_1(x)]^2}\,dx. \]

This formula is used to find the general solution \(y=c_1y_1+c_2y_2\) of the differential equation.

Q14. Define Lipschitz condition and find Lipschitz constant for \(f(x,y)=x^2|y|\) on \(|x|\le1, |y|\le1\). [2 Marks]

Lipschitz condition: A function \(f(x,y)\) defined on a domain \(D\subseteq\mathbb{R}^2\) is said to satisfy the Lipschitz condition in \(y\) on \(D\) if there exists a constant \(L>0\) such that

\[ |f(x,y_1)-f(x,y_2)|\le L|y_1-y_2| \]

for all \((x,y_1),(x,y_2)\in D\). The constant \(L\) is called the Lipschitz constant.

Problem: \(f(x,y)=x^2|y|\) on \(|x|\le1, |y|\le1\).

For \((x,y_1),(x,y_2)\) in the rectangle,

\[ |f(x,y_1)-f(x,y_2)|=|x^2|y_1|-x^2|y_2||=x^2\bigl||y_1|-|y_2|\bigr|\le x^2|y_1-y_2|. \]

Since \(|x|\le1\), we have \(x^2\le1\). Hence

\[ |f(x,y_1)-f(x,y_2)|\le 1\cdot|y_1-y_2|. \]

Thus the Lipschitz constant is \(L=1\).

Q15. State orthogonality condition for eigenfunctions. [2 Marks]

Consider the regular Sturm–Liouville problem

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+\bigl(q(x)+\lambda r(x)\bigr)y=0,\qquad a\le x\le b, \]

with homogeneous boundary conditions, where \(p(x)>0\) and \(r(x)>0\) on \([a,b]\).

Let \(\lambda_m\) and \(\lambda_n\) be two distinct eigenvalues, and let \(y_m(x)\) and \(y_n(x)\) be the corresponding eigenfunctions. Then the eigenfunctions satisfy the orthogonality condition:

\[ \int_a^b y_m(x)\,y_n(x)\,r(x)\,dx=0,\qquad m\neq n. \]

This means the eigenfunctions are orthogonal with respect to the weight function \(r(x)\) on the interval \([a,b]\).

If \(r(x)=1\), the condition reduces to the usual orthogonality:

\[ \int_a^b y_m(x)\,y_n(x)\,dx=0,\qquad m\neq n. \]

Every function \(f(x)\) that is piecewise smooth on \([a,b]\) can be expanded in a series of these eigenfunctions:

\[ f(x)=\sum_{n=1}^{\infty}c_n y_n(x),\qquad c_n=\frac{\int_a^b f(x)y_n(x)r(x)\,dx}{\int_a^b y_n^2(x)r(x)\,dx}. \]

Q16. Write Green's function formula for BVP. [2 Marks]

Consider the self-adjoint boundary value problem

\[ L[y]=\frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+q(x)y=f(x),\qquad a\le x\le b, \]

with homogeneous boundary conditions

\[ B_1[y]=\alpha_1y(a)+\beta_1y'(a)=0,\qquad B_2[y]=\alpha_2y(b)+\beta_2y'(b)=0. \]

If the homogeneous problem \(L[y]=0\) with \(B_1[y]=B_2[y]=0\) has only the trivial solution, then there exists a unique Green's function \(G(x,\xi)\) such that the solution of the non-homogeneous BVP is given by

\[ \boxed{y(x)=\int_a^b G(x,\xi)\,f(\xi)\,d\xi.} \]

The Green's function \(G(x,\xi)\) satisfies:

1. \(L_xG(x,\xi)=0\) for \(x\neq \xi\).

2. \(B_1[G]=0\) and \(B_2[G]=0\) (as functions of \(x\)).

3. \(G(x,\xi)\) is continuous at \(x=\xi\).

4. Jump condition:

\[ \left.\frac{\partial G}{\partial x}\right|_{x=\xi^+} -\left.\frac{\partial G}{\partial x}\right|_{x=\xi^-} =\frac{1}{p(\xi)}. \]

Q17. Define Orthonormal system with suitable example. [2 Marks]

A set of functions \(\{\phi_n(x)\}\) defined on an interval \([a,b]\) is called an orthonormal system if it satisfies the following two conditions:

1. Orthogonality:

\[ \int_a^b \phi_m(x)\,\phi_n(x)\,dx=0,\qquad m\neq n. \]

2. Normalization:

\[ \int_a^b [\phi_n(x)]^2\,dx=1,\qquad \text{for all }n. \]

Example: The set of functions

\[ \phi_n(x)=\sqrt{\frac{2}{\pi}}\sin(nx),\qquad n=1,2,3,\ldots \]

forms an orthonormal system on the interval \([0,\pi]\).

Verification:

For \(m\neq n\):

\[ \int_0^\pi \sqrt{\frac{2}{\pi}}\sin(mx)\cdot\sqrt{\frac{2}{\pi}}\sin(nx)\,dx =\frac{2}{\pi}\int_0^\pi \sin(mx)\sin(nx)\,dx=0. \]

For \(m=n\):

\[ \int_0^\pi \left(\sqrt{\frac{2}{\pi}}\sin(nx)\right)^2dx =\frac{2}{\pi}\int_0^\pi \sin^2(nx)\,dx=\frac{2}{\pi}\cdot\frac{\pi}{2}=1. \]

Thus \(\{\phi_n(x)\}\) is an orthonormal system on \([0,\pi]\).

Q18. Transform \((t^4+t^2)\frac{d^2x}{dt^2}+2t^3\frac{dx}{dt}+3x=0\) into equivalent self-adjoint equation. [2 Marks]

The given differential equation is

\[ (t^4+t^2)\frac{d^2x}{dt^2}+2t^3\frac{dx}{dt}+3x=0. \]

Step 1: Divide throughout by \((t^4+t^2)=t^2(t^2+1)\):

\[ \frac{d^2x}{dt^2}+\frac{2t^3}{t^2(t^2+1)}\frac{dx}{dt}+\frac{3}{t^2(t^2+1)}x=0. \]

That is,

\[ \frac{d^2x}{dt^2}+\frac{2t}{t^2+1}\frac{dx}{dt}+\frac{3}{t^2(t^2+1)}x=0. \]

Step 2: Here \(P(t)=\dfrac{2t}{t^2+1}\). The integrating factor is

\[ \mu(t)=e^{\int P(t)\,dt}=e^{\int\frac{2t}{t^2+1}\,dt}=e^{\ln(t^2+1)}=t^2+1. \]

Step 3: Multiply the equation in Step 1 by \(\mu(t)=t^2+1\):

\[ (t^2+1)\frac{d^2x}{dt^2}+(t^2+1)\cdot\frac{2t}{t^2+1}\frac{dx}{dt}+(t^2+1)\cdot\frac{3}{t^2(t^2+1)}x=0. \]

Simplifying:

\[ (t^2+1)\frac{d^2x}{dt^2}+2t\frac{dx}{dt}+\frac{3}{t^2}x=0. \]

Step 4: The first two terms can be combined as a single derivative:

\[ \frac{d}{dt}\left[(t^2+1)\frac{dx}{dt}\right]+\frac{3}{t^2}x=0. \]

Therefore, the equivalent self-adjoint form is

\[ \boxed{\frac{d}{dt}\left[(t^2+1)\frac{dx}{dt}\right]+\frac{3}{t^2}x=0.} \]

Q19. Find characteristic number and characteristic function of \(y''+\lambda y=0;\ y(0)=0,\ y(\pi/2)=0\). [2 Marks]

The given boundary value problem is

\[ y''+\lambda y=0,\qquad y(0)=0,\quad y\left(\frac{\pi}{2}\right)=0. \]

Case 1: \(\lambda>0\). Let \(\lambda=k^2\) (\(k>0\)). Then the general solution is

\[ y(x)=A\cos(kx)+B\sin(kx). \]

Applying \(y(0)=0\):

\[ A\cdot 1+B\cdot 0=0\implies A=0. \]

So \(y(x)=B\sin(kx)\).

Applying \(y(\pi/2)=0\):

\[ B\sin\left(\frac{k\pi}{2}\right)=0. \]

For a nontrivial solution, \(B\neq 0\), so

\[ \sin\left(\frac{k\pi}{2}\right)=0\implies \frac{k\pi}{2}=n\pi\implies k=2n,\quad n=1,2,3,\ldots \]

Therefore, the characteristic numbers (eigenvalues) are

\[ \boxed{\lambda_n=k^2=4n^2,\qquad n=1,2,3,\ldots} \]

and the corresponding characteristic functions (eigenfunctions) are

\[ \boxed{y_n(x)=\sin(2nx),\qquad n=1,2,3,\ldots} \]

Case 2: \(\lambda\le 0\). The resulting boundary value problem has only the trivial solution \(y\equiv 0\). Hence no negative or zero characteristic numbers exist.

Q20. Find solution of \(\frac{dy}{dx}=-xe^{-y}\). [2 Marks]

The given differential equation is

\[ \frac{dy}{dx}=-xe^{-y}. \]

This is a first-order variable separable equation.

Separating the variables \(x\) and \(y\), we obtain

\[ e^{y}\,dy=-x\,dx. \]

Integrating both sides,

\[ \int e^{y}\,dy=-\int x\,dx, \]

which gives

\[ e^{y}=-\frac{x^{2}}{2}+C, \]

where \(C\) is an arbitrary constant of integration.

Taking the natural logarithm on both sides,

\[ y(x)=\ln\left(C-\frac{x^{2}}{2}\right). \]

This is the general solution of the given differential equation.

The solution is valid for \(C-\frac{x^{2}}{2}>0\), i.e., \(x^{2}<2C\), so that the argument of the logarithm remains positive.

Q21. Express \(\frac{d^3y}{dt^3} - \frac{d^2y}{dt^2} + \frac{dy}{dt} + 3y = 0\) as system of three linear differential equations. [2 Marks]

Let us introduce new variables:

\[ x_1=y,\qquad x_2=\frac{dy}{dt},\qquad x_3=\frac{d^2y}{dt^2}. \]

Differentiating these with respect to \(t\), we get

\[ x_1'=x_2,\qquad x_2'=x_3. \]

From the given third-order differential equation,

\[ \frac{d^3y}{dt^3}=\frac{d^2y}{dt^2}-\frac{dy}{dt}-3y. \]

Therefore,

\[ x_3'=x_3-x_2-3x_1. \]

Thus, the system of three first-order linear differential equations is

\[ \begin{aligned} x_1' &= x_2,\\ x_2' &= x_3,\\ x_3' &= -3x_1-x_2+x_3. \end{aligned} \]

In matrix form, this can be written as

\[ \frac{d}{dt} \begin{pmatrix} x_1\\x_2\\x_3 \end{pmatrix} = \begin{pmatrix} 0&1&0\\ 0&0&1\\ -3&-1&1 \end{pmatrix} \begin{pmatrix} x_1\\x_2\\x_3 \end{pmatrix}. \]

Q22. Define orthogonal function. [2 Marks]

A set of functions \(\{\phi_n(x)\}\) defined on an interval \([a,b]\) is said to be an orthogonal system if the integral of the product of any two distinct functions is zero.

Mathematically,

\[ \int_a^b \phi_n(x)\phi_m(x)\,dx=0,\qquad n\neq m. \]

More generally, with respect to a weight function \(w(x)>0\), the functions are orthogonal if

\[ \int_a^b \phi_n(x)\phi_m(x)w(x)\,dx=0,\qquad n\neq m. \]

If \(n=m\), the integral is non-zero and equals the square of the norm of the function:

\[ \int_a^b [\phi_n(x)]^2 w(x)\,dx=\|\phi_n\|^2\neq 0. \]

A standard example is the set \(\{\sin nx\}_{n=1}^{\infty}\) on \([-\pi,\pi]\), where

\[ \int_{-\pi}^{\pi}\sin(nx)\sin(mx)\,dx=0,\qquad n\neq m. \]

Orthogonal functions play a fundamental role in eigenfunction expansions and Fourier series.

Q23. Find characteristic roots and characteristic vectors of matrix \(\begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix}\). [2 Marks]

Let

\[ A=\begin{bmatrix}0&1\\-1&0\end{bmatrix}. \]

The characteristic equation is given by

\[ \det(A-\lambda I)=0. \]

Thus,

\[ \begin{vmatrix} -\lambda&1\\ -1&-\lambda \end{vmatrix} =\lambda^{2}+1=0. \]

Therefore, the characteristic roots (eigenvalues) are

\[ \lambda_1=i,\qquad \lambda_2=-i. \]

For \(\lambda_1=i\), the characteristic vector \(v_1\) satisfies

\[ (A-iI)v_1=0. \]

This gives

\[ \begin{bmatrix} -i&1\\ -1&-i \end{bmatrix} \begin{bmatrix} x\\y \end{bmatrix} = \begin{bmatrix} 0\\0 \end{bmatrix}. \]

From the first equation, \(-ix+y=0\), i.e., \(y=ix\).

Choosing \(x=1\), we obtain

\[ v_1=\begin{bmatrix}1\\i\end{bmatrix}. \]

Similarly, for \(\lambda_2=-i\), we get

\[ v_2=\begin{bmatrix}1\\-i\end{bmatrix}. \]

Hence, the characteristic roots are \(i,-i\) and the corresponding characteristic vectors are \(\begin{bmatrix}1\\i\end{bmatrix}\) and \(\begin{bmatrix}1\\-i\end{bmatrix}\).

Q24. Prove that every homogeneous linear equation of second order is a self adjoint differential equation. [2 Marks]

Consider a general second-order homogeneous linear differential equation

\[ y''+P(x)y'+Q(x)y=0. \]

Multiply the equation by the integrating factor

\[ \mu(x)=e^{\int P(x)\,dx}. \]

Since \(\mu'(x)=\mu(x)P(x)\), the equation becomes

\[ \mu(x)y''+\mu'(x)y'+\mu(x)Q(x)y=0. \]

The first two terms can be combined as the derivative of a product:

\[ \frac{d}{dx}\left(\mu(x)\frac{dy}{dx}\right)+\mu(x)Q(x)y=0. \]

This is of the standard self-adjoint form

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+q(x)y=0, \]

where \(p(x)=\mu(x)\) and \(q(x)=\mu(x)Q(x)\).

Hence, every homogeneous linear equation of second order can be made self-adjoint by multiplying by a suitable integrating factor.

Therefore, every such equation is a self-adjoint differential equation.

Q25. Show that Wronskian of functions \(x^2\) and \(x^2 \log x\) is non-zero. [2 Marks]

Let \(f_1(x)=x^2\) and \(f_2(x)=x^2\log x\).

The Wronskian is defined as

\[ W(f_1,f_2)(x)= \begin{vmatrix} f_1&f_2\\ f_1'&f_2' \end{vmatrix}. \]

Computing the derivatives,

\[ f_1'(x)=2x,\qquad f_2'(x)=2x\log x+x. \]

Substituting into the determinant,

\[ W= \begin{vmatrix} x^2&x^2\log x\\ 2x&2x\log x+x \end{vmatrix}. \]

Expanding,

\[ W=x^2(2x\log x+x)-(x^2\log x)(2x). \]

Simplifying,

\[ W=2x^3\log x+x^3-2x^3\log x=x^3. \]

Since \(x^3\neq 0\) for all \(x>0\), the Wronskian is non-zero.

Therefore, the functions \(x^2\) and \(x^2\log x\) are linearly independent on \((0,\infty)\).

Q26. Show that \(f(x,y) = xy^2\) satisfy Lipschitz condition on rectangle \(|x| \le 1, |y| \le 1\). Find Lipschitz constant. [2 Marks]

A function \(f(x,y)\) satisfies the Lipschitz condition in \(y\) on a domain \(D\) if there exists a constant \(L>0\) such that

\[ |f(x,y_1)-f(x,y_2)|\le L|y_1-y_2| \]

for all \((x,y_1),(x,y_2)\in D\).

For \(f(x,y)=xy^2\), we have

\[ |f(x,y_1)-f(x,y_2)|=|xy_1^2-xy_2^2| =|x|\,|y_1^2-y_2^2|. \]

Using the factorization \(y_1^2-y_2^2=(y_1-y_2)(y_1+y_2)\),

\[ |f(x,y_1)-f(x,y_2)|=|x|\,|y_1-y_2|\,|y_1+y_2|. \]

Given \(|x|\le 1\) and \(|y|\le 1\), we have

\[ |x|\le 1,\qquad |y_1+y_2|\le |y_1|+|y_2|\le 2. \]

Therefore,

\[ |f(x,y_1)-f(x,y_2)|\le 1\cdot 2\cdot |y_1-y_2|=2|y_1-y_2|. \]

Hence, \(f(x,y)\) satisfies the Lipschitz condition on the given rectangle with Lipschitz constant \(L=2\).

Q27. State Picard's Local Existence and Uniqueness Theorem. [2 Marks]

Let \(R=\{(x,y): |x-x_0|\le a,\ |y-y_0|\le b\}\). Suppose \(f(x,y)\) is continuous on \(R\) and satisfies the Lipschitz condition in \(y\) on \(R\), i.e.

\[ |f(x,y_1)-f(x,y_2)|\le L|y_1-y_2| \]

for some constant \(L>0\).

Then the initial value problem

\[ \frac{dy}{dx}=f(x,y),\qquad y(x_0)=y_0 \]

has a unique solution \(y=y(x)\) on the interval

\[ |x-x_0|\le h,\qquad h=\min\left(a,\frac{b}{M}\right), \]

where \(M=\max_R|f(x,y)|\).

The solution is obtained as the uniform limit of Picard's iterates.

Q28. Define initial value problem and boundary value problem. [2 Marks]

Initial Value Problem (IVP):

An initial value problem consists of an ordinary differential equation together with conditions prescribed at a single point (usually \(x=x_0\)) of the interval. For a first-order equation,

\[ \frac{dy}{dx}=f(x,y),\qquad y(x_0)=y_0. \]

For a second-order equation,

\[ y''=f(x,y,y'),\qquad y(x_0)=y_0,\quad y'(x_0)=y_1. \]

Boundary Value Problem (BVP):

A boundary value problem consists of an ordinary differential equation together with conditions prescribed at two or more distinct points (usually the endpoints \(x=a\) and \(x=b\)). For a second-order equation,

\[ y''+P(x)y'+Q(x)y=R(x),\qquad a\le x\le b, \]

with

\[ \alpha_1y(a)+\beta_1y'(a)=\gamma_1,\qquad \alpha_2y(b)+\beta_2y'(b)=\gamma_2. \]

Unlike an IVP, a BVP may have no solution, a unique solution, or infinitely many solutions.

Q29. Define system of first-order differential equations. [2 Marks]

A system of first-order differential equations is a collection of equations involving first derivatives of several unknown functions of a single independent variable. In general form, it can be written as

\[ \frac{dx_1}{dt}=f_1(t,x_1,x_2,\ldots,x_n), \]

\[ \frac{dx_2}{dt}=f_2(t,x_1,x_2,\ldots,x_n), \]

\[ \vdots \]

\[ \frac{dx_n}{dt}=f_n(t,x_1,x_2,\ldots,x_n). \]

Using vector notation, if \(\mathbf{x}=(x_1,x_2,\ldots,x_n)^T\) and \(\mathbf{f}=(f_1,f_2,\ldots,f_n)^T\), the system can be written compactly as

\[ \frac{d\mathbf{x}}{dt}=\mathbf{f}(t,\mathbf{x}). \]

If the functions \(f_i\) are linear in \(x_1,\ldots,x_n\), the system is called a linear system and can be expressed in matrix form as

\[ \frac{d\mathbf{x}}{dt}=A(t)\mathbf{x}+\mathbf{b}(t), \]

where \(A(t)\) is an \(n\times n\) matrix and \(\mathbf{b}(t)\) is a column vector. If \(\mathbf{b}(t)=\mathbf{0}\), the system is homogeneous; otherwise it is non-homogeneous.

Any \(n\)-th order linear ODE can be transformed into an equivalent system of \(n\) first-order equations by introducing new variables for the derivatives.

Q30. State Picard's Theorem of Successive Approximations. [2 Marks]

Picard's Theorem of Successive Approximations (also known as Picard–Lindelöf Theorem) states:

Consider the initial value problem

\[ \frac{dy}{dx}=f(x,y),\qquad y(x_0)=y_0. \]

Let \(R=\{(x,y): |x-x_0|\le a,\ |y-y_0|\le b\}\). Suppose:

1. \(f(x,y)\) is continuous on \(R\), so \(|f(x,y)|\le M\) for some \(M>0\) on \(R\).

2. \(f(x,y)\) satisfies the Lipschitz condition in \(y\) on \(R\), i.e., there exists \(L>0\) such that

\[ |f(x,y_1)-f(x,y_2)|\le L|y_1-y_2| \]

for all \((x,y_1),(x,y_2)\in R\).

Then the IVP has a unique solution \(y=y(x)\) on the interval

\[ |x-x_0|\le h,\qquad h=\min\left(a,\frac{b}{M}\right). \]

Moreover, this solution is the uniform limit of the sequence of Picard iterates \(\{y_n(x)\}\) defined by

\[ y_0(x)=y_0,\qquad y_{n+1}(x)=y_0+\int_{x_0}^{x}f(t,y_n(t))\,dt,\quad n=0,1,2,\ldots \]

That is, \(y_n(x)\to y(x)\) uniformly on \(|x-x_0|\le h\) as \(n\to\infty\).

Q31. Condition of continuity of \(f(x,y)\) is not necessary for existence of solution. [2 Marks] Justify with example. [2/3 Marks]

The continuity of \(f(x,y)\) is a sufficient condition for the existence of a solution of the IVP \(\frac{dy}{dx}=f(x,y),\ y(x_0)=y_0\), but it is not necessary.

Example: Consider the initial value problem

\[ \frac{dy}{dx}=f(x,y),\qquad y(0)=0, \]

where

\[ f(x,y)=\begin{cases} 1, & y\ge 0,\\ -1, & y<0. \end{cases} \]

The function \(f(x,y)\) is discontinuous at \(y=0\) (and hence at the initial point \((0,0)\)).

However, the function \(y(x)=x\) is a solution of the IVP, because:

\[ y'(x)=1=f(x,y)\quad\text{for }x\ge 0, \]

and \(y(0)=0\).

Thus, even though \(f(x,y)\) is not continuous at the initial point, the IVP still has a solution. Hence, continuity of \(f(x,y)\) is not necessary for existence.

Q33. Show that differential equation \(x^2 \frac{d^2y}{dx^2} + x \frac{dy}{dx} + y = 0\) is self adjoint. [2/3 Marks]

A second-order linear differential equation is said to be in self-adjoint form if it can be expressed as

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+q(x)y=0. \]

The given equation is

\[ x^{2}y''+xy'+y=0. \]

Dividing throughout by \(x\) (for \(x\neq 0\)), we get

\[ xy''+y'+\frac{1}{x}y=0. \]

Observe that the first two terms can be combined as the derivative of a product:

\[ \frac{d}{dx}\left(x\frac{dy}{dx}\right)=x y''+y'. \]

Substituting this back into the equation, we obtain

\[ \frac{d}{dx}\left(x\frac{dy}{dx}\right)+\frac{1}{x}y=0. \]

This is precisely the standard self-adjoint form

\[ \frac{d}{dx}\left(p(x)\frac{dy}{dx}\right)+q(x)y=0, \]

where \(p(x)=x\) and \(q(x)=\frac{1}{x}\).

Hence, the given differential equation is self-adjoint.

Q36. Define Pfaffian differential equation with example. [3 Marks]

A Pfaffian differential equation is a first-order partial differential equation of the form

\[ P(x,y,z)\,dx+Q(x,y,z)\,dy+R(x,y,z)\,dz=0, \]

where \(P,Q,R\) are functions of the variables \(x,y,z\).

In two variables, it reduces to

\[ P(x,y)\,dx+Q(x,y)\,dy=0. \]

The necessary and sufficient condition for the integrability of a Pfaffian equation is

\[ P\left(\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z}\right) +Q\left(\frac{\partial P}{\partial z}-\frac{\partial R}{\partial x}\right) +R\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)=0. \]

If this condition is satisfied, the Pfaffian equation is integrable and possesses a solution of the form

\[ \phi(x,y,z)=C, \]

where \(C\) is an arbitrary constant.

A simple example is the Pfaffian equation

\[ y\,dx+x\,dy=0. \]

This can be written as

\[ d(xy)=0, \]

which gives the solution

\[ xy=C. \]

Thus, the given Pfaffian equation is integrable and represents a family of rectangular hyperbolas.

Q40. If \(y_1(x) = \sin 3x\) and \(y_2(x) = \cos 3x\) are two solutions of \(y'' + 9y = 0\), show \(y_1\) and \(y_2\) are linearly independent solutions. [3 Marks]

\[ y_1'=3\cos 3x,\qquad y_1''=-9\sin 3x=-9y_1. \]

Thus,

\[ y_1''+9y_1=0. \]

\[ y_2'=-3\sin 3x,\qquad y_2''=-9\cos 3x=-9y_2. \]

Thus,

\[ y_2''+9y_2=0. \]

Q41. If \(S\) is defined by rectangle \(|x| \le a, |y| \le b\). Show that \(f(x,y) = x^2 + y^2\) satisfy Lipschitz condition. Find Lipschitz constant. [3 Marks]

A function \(f(x,y)\) satisfies the Lipschitz condition in \(y\) on a domain \(S\) if there exists a constant \(L>0\) such that

\[ |f(x,y_1)-f(x,y_2)|\le L|y_1-y_2| \]

for all \((x,y_1),(x,y_2)\in S\).

For \(f(x,y)=x^2+y^2\), we have

\[ |f(x,y_1)-f(x,y_2)| =|(x^2+y_1^2)-(x^2+y_2^2)| =|y_1^2-y_2^2|. \]

Using the factorization \(y_1^2-y_2^2=(y_1-y_2)(y_1+y_2)\),

\[ |f(x,y_1)-f(x,y_2)|=|y_1-y_2|\,|y_1+y_2|. \]

Given the rectangle \(|x|\le a, |y|\le b\), we have

\[ |y_1|\le b,\qquad |y_2|\le b. \]

By the triangle inequality,

\[ |y_1+y_2|\le |y_1|+|y_2|\le 2b. \]

Therefore,

\[ |f(x,y_1)-f(x,y_2)|\le 2b|y_1-y_2|. \]

Hence, \(f(x,y)\) satisfies the Lipschitz condition on the given rectangle with Lipschitz constant

\[ L=2b. \]

Q42. Define Wronskian. Evaluate Wronskian of functions \(y_1(x) = \sin x\) and \(y_2(x) = \sin x - \cos x\). [3 Marks]

The Wronskian of two differentiable functions \(y_1(x)\) and \(y_2(x)\) is defined as

\[ W(y_1,y_2)(x)= \begin{vmatrix} y_1(x)&y_2(x)\\ y_1'(x)&y_2'(x) \end{vmatrix} =y_1y_2'-y_1'y_2. \]

Here,

\[ y_1(x)=\sin x,\qquad y_2(x)=\sin x-\cos x. \]

Differentiating,

\[ y_1'(x)=\cos x,\qquad y_2'(x)=\cos x+\sin x. \]

Substituting these into the Wronskian determinant,

\[ W= \begin{vmatrix} \sin x&\sin x-\cos x\\ \cos x&\cos x+\sin x \end{vmatrix}. \]

Expanding,

\[ W=\sin x(\cos x+\sin x)-(\sin x-\cos x)\cos x. \]

Simplifying,

\[ W=\sin x\cos x+\sin^2 x-\sin x\cos x+\cos^2 x. \]

Thus,

\[ W=\sin^2 x+\cos^2 x=1. \]

Therefore, the Wronskian of the given functions is

\[ W(y_1,y_2)(x)=1. \]

Since \(W\neq 0\), the functions \(y_1\) and \(y_2\) are linearly independent.

Q44. Discuss about Reduction of higher order linear differential equation into first order linear differential equation. [3 Marks]

Consider a general \(n\)-th order linear differential equation of the form

\[ y^{(n)} + P_1(x)y^{(n-1)} + P_2(x)y^{(n-2)} + \cdots + P_n(x)y = R(x). \]

To reduce this into a system of first-order linear differential equations, we introduce new dependent variables \(x_1, x_2, \ldots, x_n\) defined by

\[ x_1 = y,\quad x_2 = y',\quad x_3 = y'',\quad \ldots,\quad x_n = y^{(n-1)}. \]

Differentiating these with respect to \(x\), we obtain

\[ x_1' = x_2,\quad x_2' = x_3,\quad \ldots,\quad x_{n-1}' = x_n. \]

From the original differential equation, we can express the highest derivative as

\[ x_n' = y^{(n)} = R(x) - P_n(x)x_1 - P_{n-1}(x)x_2 - \cdots - P_1(x)x_n. \]

Thus, the given \(n\)-th order equation is transformed into a system of \(n\) first-order equations:

\[ \begin{aligned} x_1' &= x_2, \\ x_2' &= x_3, \\ &\vdots \\ x_{n-1}' &= x_n, \\ x_n' &= -P_n(x)x_1 - P_{n-1}(x)x_2 - \cdots - P_1(x)x_n + R(x). \end{aligned} \]

In matrix form, this is written as

\[ \frac{d\mathbf{X}}{dx} = A(x)\mathbf{X} + \mathbf{F}(x), \]

where \(\mathbf{X} = [x_1, x_2, \ldots, x_n]^T\), \(A(x)\) is the companion matrix, and \(\mathbf{F}(x) = [0, 0, \ldots, R(x)]^T\).

For example, the equation \(y''' - 2y'' + 3y' - 4y = e^x\) reduces to the system:

\[ \begin{bmatrix} x_1' \\ x_2' \\ x_3' \end{bmatrix} = \begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 1 \\ 4 & -3 & 2 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} + \begin{bmatrix} 0 \\ 0 \\ e^x \end{bmatrix}. \]

This reduction is fundamental in the theory of linear systems and allows the application of matrix methods.
